# 🎬 MovieHub

A modern movie, anime, and web series discovery app built with **React, Firebase, and TMDB API**.

## ✨ Features

- 🔥 Trending Movies, Anime & Web Series
- 🔐 Firebase Authentication — Google & Email/Password
- ❤️ Favorites & 🔖 Watchlist with cloud sync
- 📋 Create Public & Private Lists
- 🎭 Actor Pages with Filmography
- 🎬 Movie & Series Trailers
- 📺 Where to Watch information
- 📱 PWA — Installable on Mobile & Desktop
- 🌸 Dedicated Anime Section
- ⚡ Fast and responsive UI

---

## 🛠️ Tech Stack

| Category | Technology |
|---|---|
| Frontend | React 18 |
| Build Tool | Vite |
| Styling | Tailwind CSS |
| Authentication | Firebase Auth |
| Database | Cloud Firestore |
| Movie API | TMDB API |
| PWA | Service Worker + Web Manifest |
| Deployment | Vercel |
